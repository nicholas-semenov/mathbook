# Предел — интерактивный математический анализ

Самодостаточный статический учебник на русском: 78 уроков, 14 разделов, 19 лабораторий. Учебный маршрут построен по пользовательским PDF Фихтенгольца и выбранным транскриптам Shiz, Бориса Трушина и 3Blue1Brown.

## Запуск

Откройте `dist/index.html` в браузере. Все ресурсы, включая MathJax и шрифты формул, поставляются локально. Для одинакового поведения хранилища и надёжной загрузки ресурсов рекомендуется HTTP:

```sh
npm run dev
```

Адрес: `http://127.0.0.1:4173`. Установка зависимостей и сборка не нужны; сервер использует Python 3. На системах с ограничением открытия портов можно разместить содержимое `dist` на любом статическом хостинге.

```sh
npm test
```

Проверяются структура и уникальность уроков, математические разделители, локальные ресурсы, 127 состояний лабораторий и численные результаты. Для проверки JavaScript: `npm run check`.

## Содержание и охват

- 40 подробных уроков: введение и главы I–IV тома I, пункты 1–158. Числа и полнота, последовательности, пределы, функции, непрерывность, производные, дифференциалы, основные теоремы, Тейлор, интерполяция, исследование функций.
- 18 уроков: главы V–VII и дополнение тома I, пункты 159–262. Многомерный анализ, неявные функции, геометрия, продолжение.
- 20 обзорных уроков продолжения: главы VIII–XX и дополнение тома III, пункты 263–762. Интегралы, ряды, многомерное интегрирование и Фурье.

Уроки объединяют связанные пункты. Это не постраничная замена трёх томов и не воспроизведение всех доказательств книги. Полный список источников и конкретные ограничения размещены на странице «Источники». Исходные PDF и транскрипты не включены в публикуемый сайт.

Подробная программа: `dist/course-plan.json`. Протокол чтения источников: `dist/source-review.json`. Математическая редактура ядра: `dist/math-review.json`.

## Структура

- `dist/data.js` — авторское содержание уроков, упражнения, источники и структура курса; канонический набор данных готового сайта.
- `dist/app.js` — маршрутизация по hash, поиск, навигация, упражнения, записи и прогресс.
- `dist/labs.js` — SVG-графики и математические модели всех лабораторий.
- `dist/styles.css` — адаптивный интерфейс и режим чтения.
- `dist/mathjax/` — MathJax 2.7.9, Apache 2.0, локальная поставка.
- `scripts/validate.mjs` — проверки без внешних зависимостей.
- `.openai/hosting.json` — идентификатор созданного приватного проекта Sites и каталог статических ресурсов.

Прогресс и заметки сохраняются в `localStorage` под ключом `predel-v1`. В разделе «Мои записи» есть экспорт/импорт JSON. Импорт объединяет отметки; импортированные заметки для совпадающих уроков заменяют текущие. Приватный режим, блокировка хранилища и открытие через `file:` могут ограничивать сохранение; в этом случае доступен экспорт из текущей вкладки.

## Лаборатории

Вложенные отрезки; последовательности; атлас функций; ε–δ; разрывы и изломы; секущая/касательная; площадь произведения; цепное правило; дисконтирование и чувствительности; выпуклость; теорема Лагранжа; численное дифференцирование; Тейлор; интерполяция; Ньютон; градиент; суммы Римана; ряды и Чезаро; Фурье и Фейер.
